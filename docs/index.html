🧵 threads-autopilot

Let your AI agent use Threads for you: post text or images, reply, like and repost. Works with Gemini (Antigravity), Claude Code and Codex. No Meta API.

Deixe seu agente de IA usar o Threads por você: postar texto ou imagem, responder, curtir e repostar. Funciona com Gemini (Antigravity), Claude Code e Codex. Sem API da Meta.

Install on Windows (one command)

Instalar no Windows (um comando)

Open PowerShell, paste this and press Enter:

Abra o PowerShell, cole isto e aperte Enter:

irm https://raw.githubusercontent.com/mur4i/threads-autopilot/main/install.ps1 | iex
  1. Installs what is missing: Node.js and the Antigravity CLI (agy).
  2. Downloads the skill into Antigravity's skills folder.
  3. Opens a browser window: sign in to Threads and close the window.
  1. Instala o que faltar: Node.js e o Antigravity CLI (agy).
  2. Baixa a skill pra pasta de skills do Antigravity.
  3. Abre uma janela do navegador: entre no Threads e feche a janela.

Then open a new terminal, run agy and ask it to post something.

Depois abra um terminal novo, rode agy e peça pra ele postar algo.

Run the same command again any time to update.

Rode o mesmo comando de novo quando quiser atualizar.

macOS / Linux / Claude Code / Codex

macOS / Linux / Claude Code / Codex

With Node 18+ and Chrome installed, clone into your agent's skills folder and sign in:

Com Node 18+ e Chrome instalados, clone na pasta de skills do seu agente e faça o login:

git clone https://github.com/mur4i/threads-autopilot ~/.claude/skills/threads-autopilot
cd ~/.claude/skills/threads-autopilot && node scripts/login.mjs

Codex: ~/.codex/skills. Gemini CLI / agy: ~/.gemini/config/skills.

Codex: ~/.codex/skills. Gemini CLI / agy: ~/.gemini/config/skills.

Safe by default

Seguro por padrão

  1. The agent shows a preview and only posts after you say yes.
  2. You sign in yourself. The agent never sees your password.
  3. No bulk liking, following or replying.
  1. O agente mostra um print e só posta depois do seu sim.
  2. Você mesmo faz o login. O agente nunca vê sua senha.
  3. Nada de curtir, seguir ou responder em massa.

Sem ligação com a Meta ou o Threads. Automatizar o site do Threads pode ir contra os Termos de Uso da Meta; use na sua própria conta, em ritmo humano, por sua conta e risco.

Contribua
